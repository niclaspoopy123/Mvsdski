## Mvsd Script

A versatile utility script for the Mvsdski project.

### Usage

```bash
./mvsd.sh [COMMAND] [OPTIONS]
```

### Available Commands

- `help` - Show help message and usage information
- `version` - Display version information
- `info` - Display system information
- `greet [name]` - Greet someone (default: Sigma boy)

### Examples

```bash
# Show help
./mvsd.sh help

# Display version
./mvsd.sh version

# Show system information
./mvsd.sh info

# Greet default (Sigma boy)
./mvsd.sh greet

# Greet a specific person
./mvsd.sh greet "John Doe"
```

### Installation

Make the script executable:
```bash
chmod +x mvsd.sh
```
